# Mathematical Formulations and Heuristic Analysis in Pathfinding

This document provides a comprehensive mathematical reference for pathfinding algorithms, the foundational formulations of $A^*$ search, and a detailed examination of how heuristic functions govern node expansions, search frontiers, and optimality guarantees.

---

## 1. Foundational Pathfinding Formulations ($A^*$ Framework)

### 1.1 Graph Model and State Representation
A navigation environment is modeled as a directed or undirected graph:
$$G = (V, E)$$
where:
- $V$: Set of discrete spatial vertices (e.g., coordinates $(x, y) \in \mathbb{Z}^2$).
- $E \subseteq V \times V$: Set of valid traversable transitions (edges).
- $c(u, v) > 0$: Cost associated with traversing the edge from node $u$ to node $v$.

For an orthogonal 4-connected grid:
$$c(u, v) = 1.0, \quad \forall (u, v) \in E \text{ with } |x_u - x_v| + |y_u - y_v| = 1$$

For an 8-connected grid permitting diagonal transitions:
$$c(u, v) = \begin{cases} 1.0 & \text{if orthogonal } (|x_u - x_v| + |y_u - y_v| = 1) \\ \sqrt{2} \approx 1.414 & \text{if diagonal } (|x_u - x_v| = 1 \land |y_u - y_v| = 1) \end{cases}$$

---

### 1.2 The Core $A^*$ Cost Functions
At any arbitrary state $n \in V$, the evaluation function $f(n)$ represents the estimated total cost of an optimal path constrained to pass through node $n$ from start node $s$ to goal node $\gamma$:

$$f(n) = g(n) + h(n)$$

#### 1. Exact Accumulated Cost $g(n)$
$g(n)$ denotes the exact, cheapest accumulated path cost found so far from the start vertex $s$ to vertex $n$:
$$g(s) = 0$$
$$g(v) = \min_{(u, v) \in E} \left[ g(u) + c(u, v) \right]$$

#### 2. Heuristic Estimate $h(n)$
$h(n)$ is a domain-dependent estimate of the minimal path cost from vertex $n$ to the goal vertex $\gamma$:
$$h(\gamma) = 0$$
$$h(n) \ge 0, \quad \forall n \in V$$

#### 3. Total Priority Function $f(n)$
$f(n)$ ranks states inside the min-heap priority queue ($\text{OpenSet}$):
$$\text{Priority}(n) = f(n) = g(n) + h(n)$$
$$\text{Next Node to Expand} = \arg\min_{n \in \text{OpenSet}} f(n)$$

---

### 1.3 State Transitions and Edge Relaxation
When a state $u$ is popped from the $\text{OpenSet}$ (min-heap), all valid adjacent neighbors $v \in \text{Adj}(u)$ are evaluated through edge relaxation:

$$\text{tentative\_g} = g(u) + c(u, v)$$

The neighbor $v$ is updated if and only if a strictly shorter path has been discovered:
$$\text{If } \text{tentative\_g} < g(v):$$
$$\begin{aligned}
g(v) &\leftarrow \text{tentative\_g} \\
\text{parent}(v) &\leftarrow u \\
f(v) &\leftarrow g(v) + h(v) \\
\text{OpenSet} &\leftarrow \text{OpenSet} \cup \{v\}
\end{aligned}$$

---

### 1.4 Deterministic Tie-Breaking
When multiple candidate nodes in the $\text{OpenSet}$ have identical $f(n)$ values, naive implementations expand arbitrary nodes, generating wide search waves. A deterministic tie-breaker favors nodes with greater $g(n)$ (nodes closer to the goal depth) or inflates $h$ by a negligible factor $\epsilon \approx 10^{-4}$:

$$f_{\text{tie}}(n) = f(n) \times (1 + \epsilon) - g(n) \times \epsilon$$
$$\text{or equivalently: } f_{\text{tie}}(n) = f(n) + \frac{h(n)}{10000}$$

This breaks ties toward the goal without violating theoretical admissibility.

---

## 2. Theoretical Theorems: Admissibility and Consistency

### 2.1 Admissibility ($h(n) \le h^*(n)$)
Let $h^*(n)$ denote the true, optimal cost from node $n$ to goal $\gamma$ in graph $G$.

> **Definition (Admissibility)**: A heuristic $h(n)$ is admissible if it never overestimates the true cost to reach the goal:
> $$0 \le h(n) \le h^*(n), \quad \forall n \in V$$

#### Optimality Theorem
If $h(n)$ is admissible, $A^*$ tree search and graph search (with reopening or consistency) are **guaranteed to find an optimal shortest path**:
$$C^* = g(\gamma) = \min_{p \in \text{Paths}(s \to \gamma)} \text{cost}(p)$$

*Proof Sketch*: Suppose $A^*$ terminates with a suboptimal goal $\gamma_2$ with cost $g(\gamma_2) > C^*$. Before selecting $\gamma_2$, there must exist an unexpanded node $n'$ on the optimal path in the $\text{OpenSet}$. By admissibility, $f(n') = g(n') + h(n') \le g(n') + h^*(n') = C^*$. Since $C^* < g(\gamma_2) = f(\gamma_2)$, $n'$ must have a strictly smaller $f$-value than $\gamma_2$ and would have been selected from the min-heap before $\gamma_2$. Contradiction.

---

### 2.2 Consistency / Monotonicity ($h(u) \le c(u, v) + h(v)$)

> **Definition (Consistency / Monotonicity)**: A heuristic $h(n)$ is consistent if for every node $u$ and every successor $v$ of $u$ generated by action $c(u, v)$, the triangle inequality holds:
> $$h(u) \le c(u, v) + h(v)$$

#### Consequences of Consistency:
1. **Monotonically Non-Decreasing $f$-Values**:
   $$f(v) = g(v) + h(v) = g(u) + c(u, v) + h(v) \ge g(u) + h(u) = f(u)$$
   $$\therefore f(v) \ge f(u)$$
2. **No Re-expansions (Optimal Closed Set)**:
   When a node $u$ is selected from the min-heap, its $g(u)$ value is already optimal. Once added to the $\text{ClosedSet}$, it **never needs to be re-evaluated or re-expanded**.

---

## 3. Heuristic Formulations & Mathematical Analysis

Let current coordinate be $n = (x_n, y_n)$ and goal coordinate be $\gamma = (x_g, y_g)$.
Define coordinate displacements:
$$\Delta x = |x_n - x_g|$$
$$\Delta y = |y_n - y_g|$$

```
+--------------------------------------------------------------------------------------------------------------------------------------------------+
| Heuristic                     | Formula $h(n)$                                              | Norm Metric           | Admissible? | Consistent? |
+--------------------------------------------------------------------------------------------------------------------------------------------------+
| Zero (Dijkstra)               | $0$                                                         | Degenerate ($L_0$)    | Yes         | Yes         |
| Manhattan                     | $\Delta x + \Delta y$                                       | $L_1$ Norm (Taxicab)  | Yes (4-way) | Yes (4-way) |
| Euclidean                     | $\sqrt{\Delta x^2 + \Delta y^2}$                            | $L_2$ Norm            | Yes (Both)  | Yes (Both)  |
| Chebyshev                     | $\max(\Delta x, \Delta y)$                                  | $L_\infty$ Norm       | Yes (8-way) | Yes (8-way) |
| Octile                        | $(\sqrt{2} - 1)\min(\Delta x, \Delta y) + \max(\Delta x, \Delta y)$ | Geometric Diagonal   | Yes (8-way) | Yes (8-way) |
| Weighted Manhattan ($w=1.5$)  | $w \cdot (\Delta x + \Delta y)$                             | Inflated $L_1$        | No ($w>1$)  | No ($w>1$)  |
+--------------------------------------------------------------------------------------------------------------------------------------------------+
```

---

### 3.1 Zero Heuristic (Dijkstra / Uniform-Cost Search)

#### Formula
$$h_{\text{Dijkstra}}(n) = 0$$
$$f_{\text{Dijkstra}}(n) = g(n) + 0 = g(n)$$

#### Mathematical Properties
- **Directional Guidance**: None. The gradient $\nabla h = \vec{0}$.
- **Expansion Geometry**: Concentric circles/diamonds spreading radially from start $s$.
- **Admissibility**: Trivial, since $0 \le h^*(n)$ for all non-negative cost graphs.
- **Complexity**: Expands every vertex $v$ satisfying $g(v) \le C^*$, resulting in maximum node expansions.

---

### 3.2 Manhattan Distance ($L_1$ Norm / Taxicab Distance)

#### Formula
$$h_{\text{Manhattan}}(n) = \|\vec{n} - \vec{\gamma}\|_1 = \Delta x + \Delta y = |x_n - x_g| + |y_n - y_g|$$
$$f(n) = g(n) + (\Delta x + \Delta y)$$

#### Mathematical Properties
- **Domain**: 4-connected orthogonal grid environments where diagonal movement is disallowed.
- **Admissibility on 4-Way Grids**: In an obstacle-free grid, the minimum path between $(x_n, y_n)$ and $(x_g, y_g)$ consists of $\Delta x$ horizontal steps and $\Delta y$ vertical steps. Therefore:
  $$h_{\text{Manhattan}}(n) = h^*_{\text{free}}(n) \le h^*(n)$$
- **Consistency**: Moving orthogonally changes $|x_n - x_g| + |y_n - y_g|$ by at most $\pm 1$:
  $$|h(u) - h(v)| \le 1 = c(u, v) \implies h(u) \le 1 + h(v)$$
- **Theoretical Optimality**: On 4-way grids, Manhattan is the **tightest possible admissible heuristic** across all $L_p$ norms.

---

### 3.3 Euclidean Distance ($L_2$ Norm / Straight-Line Metric)

#### Formula
$$h_{\text{Euclidean}}(n) = \|\vec{n} - \vec{\gamma}\|_2 = \sqrt{\Delta x^2 + \Delta y^2} = \sqrt{(x_n - x_g)^2 + (y_n - y_g)^2}$$
$$f(n) = g(n) + \sqrt{(x_n - x_g)^2 + (y_n - y_g)^2}$$

#### Mathematical Properties
- **Admissibility**: By Euclidean triangle inequality, straight-line distance is the shortest possible path in continuous $\mathbb{R}^2$. Any discrete grid path must satisfy:
  $$h_{\text{Euclidean}}(n) \le h^*_{\text{discrete}}(n)$$
- **Underestimation on 4-Way Grids**:
  For any non-axis-aligned displacement ($\Delta x > 0, \Delta y > 0$):
  $$\sqrt{\Delta x^2 + \Delta y^2} < \Delta x + \Delta y$$
  For example, when $\Delta x = 1, \Delta y = 1$:
  $$h_{\text{Euclidean}} = \sqrt{1^2 + 1^2} = \sqrt{2} \approx 1.414 < 2 = h_{\text{Manhattan}}$$
  This systemic underestimation creates loose lower bounds, causing $A^*$ to expand a wider ellipse of nodes than Manhattan.

---

### 3.4 Chebyshev Distance ($L_\infty$ Norm / Chess King's Metric)

#### Formula
$$h_{\text{Chebyshev}}(n) = \|\vec{n} - \vec{\gamma}\|_\infty = \max(\Delta x, \Delta y) = \max(|x_n - x_g|, |y_n - y_g|)$$
$$f(n) = g(n) + \max(|x_n - x_g|, |y_n - y_g|)$$

#### Mathematical Properties
- **Domain**: 8-connected grid where diagonal movement is permitted at unit cost ($c_{\text{diag}} = 1$).
- **Underestimation on 4-Way Grids**:
  Because diagonal movement is prohibited in 4-way mode, each diagonal displacement requires 2 orthogonal steps. Thus:
  $$\max(\Delta x, \Delta y) \le \frac{1}{2}(\Delta x + \Delta y) \ll h^*(n)$$
  For $\Delta x = 10, \Delta y = 10$:
  $$h_{\text{Chebyshev}} = 10 \quad \text{vs} \quad h^* = 20$$
  The heuristic underestimates true distance by $50\%$, leading to heavy node expansion penalties resembling Dijkstra search.

---

### 3.5 Octile Distance (Exact Diagonal Grid Metric)

#### Formula
When diagonal movement has cost $c_{\text{diag}} = \sqrt{2} \approx 1.414$ and orthogonal movement has cost $c_{\text{ortho}} = 1.0$:

$$h_{\text{Octile}}(n) = (\sqrt{2} - 1) \cdot \min(\Delta x, \Delta y) + \max(\Delta x, \Delta y)$$

Alternatively factored:
$$h_{\text{Octile}}(n) = c_{\text{diag}} \cdot \min(\Delta x, \Delta y) + c_{\text{ortho}} \cdot (\max(\Delta x, \Delta y) - \min(\Delta x, \Delta y))$$

#### Derivation
1. The robot takes $\min(\Delta x, \Delta y)$ diagonal steps to align either horizontal or vertical coordinate with the goal. Each costs $\sqrt{2}$.
2. The remaining $|\Delta x - \Delta y| = \max(\Delta x, \Delta y) - \min(\Delta x, \Delta y)$ steps are traversed orthogonally at cost $1$.
3. Total cost:
   $$\sqrt{2} \min(\Delta x, \Delta y) + \max(\Delta x, \Delta y) - \min(\Delta x, \Delta y) = (\sqrt{2} - 1)\min(\Delta x, \Delta y) + \max(\Delta x, \Delta y)$$

---

### 3.6 Weighted Manhattan Distance ($\epsilon$-Admissible / Inadmissible Search)

#### Formula
$$h_w(n) = w \cdot h_{\text{Manhattan}}(n) = w \cdot (|x_n - x_g| + |y_n - y_g|), \quad w > 1$$
$$f_w(n) = g(n) + w \cdot h(n)$$

#### Mathematical Guarantees
- **Admissibility**: Inadmissible ($w > 1 \implies h_w(n) > h^*(n)$ for many states).
- **Bounded Suboptimality Theorem**: The returned path cost $C$ is provably bounded within a factor of $w$ from the true optimum $C^*$:
  $$C \le w \cdot C^*$$
- **Pruning Effect**: By overweighting $h(n)$, $f$-contours become narrow paraboloids pointed toward the goal, converting $A^*$ into a greedy, depth-first search that bypasses wide exploration at the cost of slight suboptimality.

---

## 4. Vector Angle and Directional Heading Formulation

The directional displacement vector $\vec{d}$ from current node $(x_n, y_n)$ to goal $(x_g, y_g)$ is:
$$\vec{d} = \begin{bmatrix} x_g - x_n \\ y_g - y_n \end{bmatrix} = \begin{bmatrix} d_x \\ d_y \end{bmatrix}$$

The continuous angle of orientation $\theta \in [0^\circ, 360^\circ)$ relative to the positive x-axis is:
$$\theta = \text{atan2}(d_y, d_x) \times \frac{180}{\pi} \pmod{360}$$

For discrete adjacent robot heading transitions between step $t$ and $t+1$:
$$\text{heading} = \begin{cases}
0^\circ & \text{if } \Delta x = +1, \Delta y = 0 \quad (\text{East}) \\
90^\circ & \text{if } \Delta x = 0, \Delta y = +1 \quad (\text{South}) \\
180^\circ & \text{if } \Delta x = -1, \Delta y = 0 \quad (\text{West}) \\
270^\circ & \text{if } \Delta x = 0, \Delta y = -1 \quad (\text{North})
\end{cases}$$

---

## 5. Minkowski Dominance Theorem & Search Space Complexity

### 5.1 The Minkowski $L_p$ Metric Hierarchy
For any non-negative displacement $(\Delta x, \Delta y)$:
$$\|\vec{d}\|_\infty \le \|\vec{d}\|_2 \le \|\vec{d}\|_1$$
$$\max(\Delta x, \Delta y) \le \sqrt{\Delta x^2 + \Delta y^2} \le \Delta x + \Delta y$$

Incorporating the discrete grid metrics:
$$0 = h_{\text{Dijkstra}} \le h_{\text{Chebyshev}} \le h_{\text{Octile}} \le h_{\text{Euclidean}} \le h_{\text{Manhattan}} \le h^*(n)$$

---

### 5.2 Heuristic Dominance Theorem

> **Theorem (Heuristic Dominance)**: Let $h_1(n)$ and $h_2(n)$ be two admissible and consistent heuristics. If:
> $$h_2(n) \ge h_1(n), \quad \forall n \in V$$
> then $h_2$ **dominates** $h_1$. Every node expanded by $A^*$ using $h_2$ (excluding boundary ties where $f(n) = C^*$) will also be expanded by $A^*$ using $h_1$:
> $$\mathcal{S}_{\text{expanded}}(h_2) \subseteq \mathcal{S}_{\text{expanded}}(h_1)$$

#### Proof
A node $n$ is guaranteed to be expanded by $A^*$ if $f(n) < C^*$, where $C^*$ is the optimal goal cost.
Therefore:
$$\mathcal{S}_{\text{guaranteed}}(h) = \{ n \in V \mid g(n) + h(n) < C^* \}$$
Since $h_2(n) \ge h_1(n)$:
$$g(n) + h_2(n) < C^* \implies g(n) + h_1(n) < C^*$$
$$\therefore \mathcal{S}_{\text{guaranteed}}(h_2) \subseteq \mathcal{S}_{\text{guaranteed}}(h_1)$$

#### Direct Corollary on 4-Connected Grids
$$\mathcal{S}_{\text{expanded}}(h_{\text{Manhattan}}) \subseteq \mathcal{S}_{\text{expanded}}(h_{\text{Euclidean}}) \subseteq \mathcal{S}_{\text{expanded}}(h_{\text{Chebyshev}}) \subseteq \mathcal{S}_{\text{expanded}}(h_{\text{Dijkstra}})$$

This provides mathematical proof for why empirical experiments produce:
$$\text{NodesExpanded}(h_{\text{Manhattan}}) \approx 34 \ll \text{NodesExpanded}(h_{\text{Euclidean}}) \approx 52 \ll \text{NodesExpanded}(h_{\text{Dijkstra}}) \approx 189$$

## 6. Concrete Numerical Step-by-Step Substitution

Consider a concrete navigation scenario:
- **Start Coordinate**: $(2, 3)$
- **Goal Coordinate**: $(14, 14)$
- **Current Step**: Robot at $n = (5, 8)$, with accumulated cost $g(n) = 8$.

$$\Delta x = |5 - 14| = 9$$
$$\Delta y = |8 - 14| = 6$$

### Exact Formula Substitution Table for $n = (5, 8)$:

| Heuristic | Formula | Numerical Substitution | Computed $h(n)$ | Total $f(n) = g + h$ | Admissible ($h \le 15$)? |
|:---|:---|:---|:---:|:---:|:---:|
| **Zero (Dijkstra)** | $h = 0$ | $0$ | **$0.00$** | $8 + 0 = \mathbf{8.00}$ | ✅ Yes |
| **Chebyshev** | $\max(\Delta x, \Delta y)$ | $\max(9, 6)$ | **$9.00$** | $8 + 9 = \mathbf{17.00}$ | ✅ Yes (loose) |
| **Octile** | $(\sqrt{2}-1)\min + \max$ | $0.414 \times 6 + 9 = 2.484 + 9$ | **$11.48$** | $8 + 11.48 = \mathbf{19.48}$ | ✅ Yes |
| **Euclidean** | $\sqrt{\Delta x^2 + \Delta y^2}$ | $\sqrt{9^2 + 6^2} = \sqrt{81 + 36} = \sqrt{117}$ | **$10.82$** | $8 + 10.82 = \mathbf{18.82}$ | ✅ Yes |
| **Manhattan** | $\Delta x + \Delta y$ | $9 + 6 = 15$ | **$15.00$** | $8 + 15 = \mathbf{23.00}$ | ✅ Yes (tightest) |
| **Weighted ($w=1.5$)** | $1.5 \times (\Delta x + \Delta y)$ | $1.5 \times (9 + 6) = 1.5 \times 15$ | **$22.50$** | $8 + 22.5 = \mathbf{30.50}$ | ❌ Inadmissible ($22.5 > 15$) |

Notice that the exact obstacle-free shortest path cost from $(5, 8)$ to $(14, 14)$ on a 4-way grid is $h^* = 15$.
- Manhattan yields $h(n) = 15$, matching $h^*(n)$ exactly.
- Euclidean underestimates by $15 - 10.82 = 4.18$.
- Chebyshev underestimates by $15 - 9.00 = 6.00$.
- Dijkstra underestimates by $15 - 0.00 = 15.00$.

## 7. Multi-Agent Path Finding (MAPF) Formulations

### 7.1 Collision Types

Let $p_i(t)$ be the coordinate $(x_i, y_i)$ of agent $i$ at discrete time $t$.

#### 1. Vertex Collision
Occurs when two or more distinct agents occupy the identical grid coordinate at the same timestep $t$:
$$p_i(t) = p_j(t), \quad \text{for } i \neq j$$

#### 2. Edge / Swap Collision
Occurs when two agents attempt to cross the same edge in opposite directions between timesteps $t$ and $t+1$:
$$p_i(t) = p_j(t+1) \quad \land \quad p_i(t+1) = p_j(t), \quad \text{for } i \neq j$$

---

### 7.2 Space-Time $A^*$ Formulation
State space incorporates discrete time as a third coordinate:
$$S = V \times \{0, 1, 2, \dots, T_{\max}\}$$
A state is defined as:
$$u = (x, y, t)$$

#### Valid Actions $\mathcal{A}(x, y, t)$:
1. **Orthogonal Motion**:
   $$(x \pm 1, y, t+1) \quad \text{or} \quad (x, y \pm 1, t+1)$$
2. **Wait in Place**:
   $$(x, y, t+1) \quad \text{with cost } c_{\text{wait}} = 1.0$$

#### Spatio-Temporal Reservation Table $\mathcal{R}$:
$$\mathcal{R}_{\text{vertex}}(x, y, t) \in \{\text{free}, \text{occupied\_by\_agent\_} k\}$$
$$\mathcal{R}_{\text{edge}}((u, v), t) \in \{\text{free}, \text{reserved\_by\_agent\_} k\}$$

A transition from $(u, t)$ to $(v, t+1)$ is admissible if and only if:
$$\mathcal{R}_{\text{vertex}}(v, t+1) = \text{free} \quad \land \quad \mathcal{R}_{\text{edge}}((v, u), t) = \text{free}$$

---

### 7.3 Conflict-Based Search (CBS)

CBS decomposes MAPF into a two-level optimization:

#### Low-Level Search
Standard Space-Time $A^*$ finding a path for a single agent $a_i$ subject to a set of specific spatio-temporal constraints:
$$\text{Constraints}(a_i) = \{ (v, t) \mid a_i \text{ cannot occupy } v \text{ at time } t \}$$

#### High-Level Search
Explores a **Constraint Tree (CT)** via branch-and-bound search:
- **Node $N$**: Contains a set of constraints across all agents, a set of individual paths $\{p_1, p_2, \dots, p_K\}$, and total cost:
  $$\text{Cost}(N) = \text{SIC} = \sum_{i=1}^K \text{cost}(p_i) \quad (\text{Sum of Costs})$$
- **Conflict Detection**: Find the earliest collision $(a_i, a_j, v, t)$ or $(a_i, a_j, u, v, t)$.
- **Branching**: Branch node $N$ into two child nodes:
  - Child 1: Adds constraint $(a_i, v, t)$ (agent $i$ forbidden from $v$ at $t$).
  - Child 2: Adds constraint $(a_j, v, t)$ (agent $j$ forbidden from $v$ at $t$).

Since high-level nodes are expanded by lowest total cost $\text{SIC}$, CBS is **guaranteed to find the globally optimal, collision-free solution**.
